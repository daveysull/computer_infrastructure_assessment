# computer_infrastructure_assessment

Contents

1) weather.ipynb
This notebook contains the nine tasks completed throughout the semester. These tasks progressively built the skills and knowledge required to process and handle weather data using shell scripting and related tools.

2) weather.sh
This file is the final output of the tasks and serves as the main script for automating weather data retrieval and processing. It incorporates all the techniques learned during the semester.

3) .github/workflows/weather-data.yml
This GitHub Actions workflow automates the execution of the weather.sh script. It schedules the script to run daily or allows for manual execution, ensuring up-to-date weather data is always available.

4) project_explanation.ipynb
This notebook contains a detailed explanation on how the syntax in weather.sh and weather-data.yml works.

Purpose

This repository demonstrates the application of foundational computer infrastructure concepts, focusing on task automation, script development, and integration with GitHub Actions.
